Светские похороны в Алматы

Прощание без обязательного религиозного чина: достойный формат, который выбирают семьи с разными взглядами или по воле усопшего.

Как выглядит светский формат

Фокус на прощании близких: зал или камерная встреча, возможность сказать слова, музыка по желанию, затем кладбище или кремация. Религиозные элементы не навязываем.

Если часть родственников всё же хочет короткую молитву — добавляем точечно, без конфликта сценария.

Организация без лишнего

Собираем маршрут, транспорт, оформление зала, список гостей по таймингу. Помогаем с речью и порядком выхода к месту прощания — тем, кому трудно говорить в этот день.

Смета остаётся прозрачной: платите за выбранные позиции.

Память после церемонии

Памятник, табличка, благоустройство — когда будете готовы. Для светского места захоронения подбираем сдержанный дизайн без обязательной религиозной символики.
